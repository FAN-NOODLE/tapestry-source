## Row 布局行

### 介绍
Layout 提供了van-row和van-col两个组件来进行行列布局。

### Props

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| ----- | ----- | ----- | ----- | ----- |
| gutter | 列元素之间的间距（单位为 px） | string \| number | -- | -- |

### Slots

| name  | 说明 |
| ----- | ----- |
| default | 默认插槽 |


### 外部样式类

| 类名  | 说明 |
| ----- | ----- |
| custom-class | 根节点样式类 |
